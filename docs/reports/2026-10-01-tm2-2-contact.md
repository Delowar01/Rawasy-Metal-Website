## 13. Attachment behaviour

Unchanged and tested:

- **Count:** at most 5 files; a 6th gives "You can add up to 5 files.".
- **Size:** 10 MB each. Exactly 10,485,760 bytes is accepted; one byte more gives "… is larger than 10 MB.".
- **Types:** PDF, DWG, DXF, STEP, STP, JPG, JPEG, PNG, in any letter case. Others (`.exe`, `.txt`) give "… isn't a
  supported file type.".
- **List:** a duplicate is listed once. Removing a file clears the notices and returns focus to the picker.
- **Announcements:** notices go to a polite live region.
- **Nothing leaves the device:** only names go into the request ("Files to attach: …"), and nothing is uploaded — no
  non-GET request at all during the flow (tested).

New look:

- a dashed drop zone (focus ring on keyboard focus);
- file rows with an icon, the name (truncated, aligned with the page direction), the size, and a 40 px remove button.

Bug found and fixed during QA: a long file name widened the file block's grid track on phones, and the card clipped the
remove button off-screen. A test was added; it failed before the fix and passes after.

## 19. Pointer over the map iframe

A cross-origin frame takes the mouse, so the MC pointer would freeze at its edge. `FramePointer` sets
`html[data-cursor-away]` on a mouse `pointerover` whose target is an iframe, and clears it on the next `pointerover`
back on the page. One CSS rule hides the pointer meanwhile.

- There is no overlay over the map.
- `Cursor.tsx` is unchanged.
- The listener ignores touch and pen.

Tested:

- pointer shown on the card;
- hidden over the map (opacity 0, attribute set);
- shown again on return;
- a touch tap on the map sets nothing (no `data-cursor-on`, no `data-cursor-away`).
